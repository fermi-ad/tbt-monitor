results_table.tex contract

The generated file contains one table* environment and no document preamble.
It is built only after the Best-N block-20 root and selected full-buffer ridge
root both pass their strict verifiers.

The table uses `\small`, `@{}` outer padding, concise headings, and an ordinary
`tabular`; it must fit `\textwidth` without `\resizebox` or an overfull box.
Agreement is rendered as a percentage, while tune and IQR quantities use
`10^{-3}` units so the two rows do not mix decimal and scientific notation.

Required columns, one H row and one V row:
- plane
- declared global operating-point N
- blind full-band selected/held-out-digitizer agreement and 95% collection-block interval
- median blind selected/held-out absolute tune delta and 95% interval
- exact-paired selected-Best-N minus corrected-adaptive-Best-1 median IQR delta
  and 95% turn-block interval

The table contains no historical-selector or intensity-study column. The
caption must distinguish spill-block Best-N intervals from turn-block ridge
intervals and state that ridge values describe exact-paired pick concentration,
not absolute tune accuracy or measured physical noise.
