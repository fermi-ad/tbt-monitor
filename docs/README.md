# Documentation

The guides are grouped by the task or question they answer.

## Operate and analyze

- [DAQ guide](DAQ.md): configure live monitoring, capture spills, and interpret
  acquisition quality.
- [Analysis chains](ANALYSIS_CHAINS.md): choose the appropriate live or offline
  Rust analysis path.
- [Usage guide](USAGE.md): CLI commands and worked examples.
- [Configuration reference](CONFIG_REFERENCE.md): runtime and analysis keys.
- [Operations](OPERATIONS.md): local builds, Docker, and output checks.

## Offline research workflows

- [Spark workflows](SPARK.md): CPU/GPU batch analysis, autosweep, and Best-BPM
  mining.
- [Poster analysis](POSTER_ANALYSIS.md): publication-oriented analysis and
  figure generation.
- [Analysis checklist](ANALYSIS_CHECKLIST.md): implemented checks, remaining
  validation questions, and acceptance boundaries.

## Understand the system

- [Architecture](ARCHITECTURE.md): modules, data flow, timing, and artifact
  contracts.
- [Design decisions](DESIGN_DECISIONS.md): rationale and important tradeoffs.
- [Physics](PHYSICS.md): scientific interpretation, limitations, and required
  external validation.
- [Current status](CURRENT_STATUS.md): accepted results and publication state.
- [Delivery Ring source audit](DELIVERY_RING_SOURCE_AUDIT.md): raw-stream and
  payload provenance used by the publication analysis.
